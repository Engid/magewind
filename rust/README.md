# magewind (Rust port)

An agent harness around the Jev System One model. See the [root README](../README.md) for the overall repo layout.

The Rust port has not started yet. The Python prototype in `python/` comes first, and both implementations share the test cases and prompts in `spec/`.

Publishing is blocked by `publish = false` in `Cargo.toml` until a release is ready. See [docs/publishing.md](../docs/publishing.md).
