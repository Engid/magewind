# magewind (TypeScript)

An agent harness around the Jev System One model. See the [root README](../README.md) for the overall repo layout.

Nothing is here yet. This folder is for a possible TypeScript prototype on [Bun](https://bun.com). If it happens, it should use the same test cases and prompts in `spec/` as the Python prototype so the two can be compared.

`"private": true` in `package.json` blocks publishing to npm until a release is ready. See [docs/publishing.md](../docs/publishing.md).
